## About Cosine

**Cosine AI** is a human reasoning lab and AI company dedicated to teaching artificial intelligence to reason like humans—focusing first on software engineering. Their mission is to codify and apply human-like reasoning to tackle the hardest problems in tech.

- **Flagship Product:** Genie, an autonomous AI software engineer trained on synthetic data that models human reasoning, including the steps and mistakes real developers make.
- **Key Capabilities:**
  - Fully autonomous, agentic software engineering
  - Handles real, complex codebases and coding tickets end-to-end
  - Works asynchronously and independently, breaking down tasks and delivering completed code for review
  - Integrates with developer workflows (Slack, Jira, Linear, etc.)
- **Industry Leadership:** Genie achieved a groundbreaking 30% score on the SWE-Bench benchmark, surpassing all other AI coding models (including GPT-4) by a wide margin.
- **Business Goal:** Cosine aims to scale software development capacity by automating coding projects, relieving bottlenecks caused by limited developer resources.
- **Company Stage:** Seed-funded startup, actively onboarding users and deploying Genie in real-world workflows.

Cosine’s approach stands apart by deeply modeling the reasoning process behind software development, not just outputting code suggestions.
